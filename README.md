# Magnetometer-Simulation
A 3D simulation of the magnetometer readings used in navigation systems, included with tilt compensation techniques for accurate yaw measurements.

Note: This simulation was primarily used as a tool for the <a href="https://github.com/Maritime-Mavericks/Software">Autonomous Rescue Boat</a> project under Maritime Mavericks.
